# Contributing

Health Habit Starter is meant to be forked and made your own. Features that fit your personal
routine belong in your fork.

Welcome here:

- Bug reports (use the issue template).
- Small fixes and improvements that help every user.

Before opening a pull request, run the [checks](docs/development.md#checks). Code conventions are in
[CLAUDE.md](CLAUDE.md), which also guides AI coding agents.
