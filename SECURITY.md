# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[Report a vulnerability](https://github.com/vinctdev/healthhabitstarter/security/advisories/new)
in the Security tab, not in a public issue. This is a one-person project, so replies are best effort.

## Out of scope

The app has no login by design. Making it reachable without access control in front of it is a
deployment choice, not a vulnerability. See
[Securing access](docs/deployment.md#securing-access).
